# Physiotherapy English

Static learning site for physiotherapy students, designed for GitHub Pages.

## Included in v1.0

- 60 physiotherapy vocabulary entries across 10 areas.
- Every vocabulary card includes: pronunciation audio via the browser's speech synthesis, English term, English definition, French translation, clinical example and a schematic illustration.
- 7 grammar modules. Every module includes a concise lesson, a BBC Learning English video and a physiotherapy recap quiz.
- Whole-site diagnostic: 34 untimed questions covering every vocabulary area and every grammar module, with an automatic revision plan.
- Dictionary, flashcards, four practice modes, pronunciation lab, six clinical cases and a communication lab.
- Saved vocabulary, progress and diagnostic history stored only in local browser storage.
- Accessibility options: font size, dark mode, high contrast, simple layout and reduced motion.
- Responsive layout for phone, tablet and desktop.
- Installable PWA / offline cache for the site's static core files.

## Deploy on GitHub Pages

1. Create a new GitHub repository (for example `PhysiotherapyEnglish`).
2. Upload **all files and folders from this ZIP to the root of the repository**. `index.html` must be at the root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for the GitHub Pages URL to appear.

No build command, npm package or framework is required.
